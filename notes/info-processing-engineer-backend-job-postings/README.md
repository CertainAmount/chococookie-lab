## 계산

- 자격 칸을 채운 공고: 고용24 직접 36건 중 12건.
- 그중 정보처리기사: 8건(자격 칸 우대 7 + 자격 칸 기타 1). 8/12.
- 나머지 4건: 필수 자동차운전면허 2, 조건 문장(컴퓨터 계열 4년제 졸업 / Python 사용 가능) 1, 우대 정보통신산업기사·사무자동화산업기사 1.
- 자격 칸이 「관계없음」이거나 빈 공고 24건. 본문에만 정보처리기사를 적은 2건은 이 24건 안에 있다.
- 36건 기준 정보처리기사 10건(27.8%). 전체 61건 기준으로는 10건(16.4%).
- 같은 36건에서 정보처리산업기사 3건(자격 칸 우대 2, 기타 1), SQLD 1건, 리눅스마스터 0건, 정보보안기사 0건.

## 수집에서 뺀 것과 이유

- 사람인·잡코리아·캐치·인크루트에서 넘어온 공고는 고용24 화면에 모집 직종 같은 요약만 있고 본문이 없어 셀 수 없었다.
- 원문 포털을 직접 수집하지 않았다. 2016년 사람인의 잡코리아 공고 크롤링 사건에서 법원은 채용 공고 데이터베이스를 보호 대상으로 봤다(서울고법 2016나2019365, [법률신문 보도](https://www.lawtimes.co.kr/news/articleView.html?idxno=98844)).
- 공공기관(알리오) 개발 공고는 수집일에 고용24 연계 목록에 0건이었다. 공공 쪽 가점은 각 기관 공고 원문으로 확인해야 한다.

## 다른 숫자와의 관계

- **한국산업인력공단 7.6%**: 2023년 고용24 채용공고 167만 4,560건 중 국가기술자격을 요건으로 정하거나 우대한 공고가 12만 7,612건(7.6%)이라는 분석이다. 전 직종, 국가기술자격 전체, 필수와 우대를 합친 값이라 이 노트의 숫자(개발 직무, 정보처리기사 한 종목)와 기준이 다르다. 공단 보도자료 원문은 찾지 못했고 언론 보도로 확인했다([서울신문 2024-11-27](https://m.go.seoul.co.kr/news/2024/11/27/20241127500105), [세계일보 2024-11-28](https://www.segye.com/newsView/20241128505438)).
- **「IT 공고 78%가 정보처리기사 우대」**: 교육업체 글에 도는 숫자다. 한국어 일반 검색과 정확 일치 검색에서 원출처나 이를 인용한 공식·언론 자료를 찾지 못했다. 출처 미상이라 글에 쓰지 않았다.

## SW기술자 등급제

글에서 SI가 정처기를 챙기는 이유는 SI 협력사 PM의 말로만 썼다. 「기사 자격에 경력이 붙으면 기술자 등급이 올라가고 그 등급이 사업 대가에 걸린다」는 설명은 현행 제도와 맞지 않아 뺐다.

- SW기술자 등급관리 기능은 2012년 폐지가 결정됐고 경력관리 기능만 남았다(지식경제부 2012-06-28 「SW기술자 신고제 개편」, [KDI 경제정보센터 게시](https://eiec.kdi.re.kr/policy/materialView.do?num=121907)).
- SW사업 대가산정 가이드는 2019년 2차 개정판부터 등급별 평균임금 대신 IT직무별 평균임금을 쓴다([디지털데일리 2019-12-24](https://www.ddaily.co.kr/page/view/2019122414102996141)).
- 제안서 평가에서 발주기관이 자격 보유 인력을 보는지는 기관별 제안요청서 사항이라 일반 규정은 확인하지 못했다.
