# 티스토리 vs 워드프레스 — 근거 노트

글의 두 판단을 확인하는 자료다. 하나는 「같은 평균 순위에서 1~3위 CTR만 떨어졌다」는 Search Console 집계이고, 다른 하나는 「tistory.com 주소는 서버 301로 넘길 수 없고, 개인 도메인을 연결해도 기존 주소가 200으로 남는다」는 공식 문서 대조와 직접 요청 결과다.

## 1. Search Console 월별 집계

- 수집: Google Search Console searchAnalytics API, 차원 `date`와 `query+page`. 기간 2025-07-01~2026-10-31. Search Console이 보여 주는 최대 범위(16개월) 안이다.
- `avg_position`: 사이트 전체 월별 평균 게재 순위. 16개 월 모두 있다. 2026-11은 1~10일뿐이라 뺐다.
- 순위대별 값(`top3_*`, `pos4_10_ctr_pct`): 검색어×페이지 행을 그 행의 평균 순위로 1~3위·4~10위로 나눠 합산했다. 3개월 간격 6개 월만 집계했고, 빈칸은 집계하지 않은 달이다(0이 아니다).
- 사이트 전체 하루 클릭(본문 「약 1,000회 → 약 400회 안팎」)은 월 하루 평균 기준 2025-07 1,026회, 2026-08 381회, 2026-09 434회, 2026-10 389회다.
- 1~3위 클릭의 글별 분해(본문 「3,378회 대 117회」): 2026-10-01~11-09, 1~3위 행만, 글 번호를 기준으로 원래 있던 글과 새로 쓴 글을 나눈 근사 분류다. 원래 있던 글 노출 43,334·클릭 3,378(CTR 7.8%), 새로 쓴 글 노출 1,042·클릭 117(CTR 11.2%).
- 집계일 2026-11-12, 정리일 2026-11-17. 원본 행은 올리지 않고 월 집계만 둔다.

## 2. 주소 이전 관련 공식 문서 대조 (2026-11-17 확인)

| 확인한 것 | 문서가 말하는 것 | 글에서 쓴 범위 |
|---|---|---|
| 서버 301 | 가능하면 서버 측 영구 리디렉션을 쓰라고 권한다 | 티스토리에서는 서버 301을 걸 수 없다 |
| 즉시 메타 새로고침 | Google은 즉시 메타 새로고침을 영구 리디렉션으로 해석한다. 지연된 것은 임시로 본다 | 스킨에서 쓸 수 있다고 확인한 방법이 자바스크립트뿐이라 본문에서는 다루지 않았다 |
| 자바스크립트 리디렉션 | 서버 측이나 메타 새로고침을 쓸 수 없을 때만 쓰라고 한다. 렌더링이 실패하면 Google이 리디렉션을 못 볼 수 있다 | 스킨 JS로 보낼 수는 있지만 권장 방식이 아니다 |
| 주소 변경 도구 | 옛 홈페이지에서 새 홈페이지로 301을 걸고 180일 이상 유지해야 하며, 옛·새 속성 모두 소유자여야 한다 | 301을 못 거는 tistory.com 주소에서는 쓸 수 없다 |
| 티스토리 개인 도메인 연결 공지 | DNS CNAME 연결 방식, 1차 주소로 되돌려도 2차 주소로 접근 가능 | 연결을 지원한다는 사실만. 기존 tistory.com 주소의 리디렉션·상태 코드는 이 공지에 없다 |

## 3. 개인 도메인 연결 블로그의 tistory.com 주소 요청 (2026-11-17)

개인 도메인을 연결해 운영 중인 다른 티스토리 블로그 한 곳의 글 주소를 요청했다. 블로그 식별자는 공개하지 않는다.

```sh
U='https://{아이디}.tistory.com/{글번호}'
for ua in 'Mozilla/5.0' 'Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)'; do
  curl -s -o /dev/null -A "$ua" -w "UA=${ua%% *}  HTTP %{http_code}  redirect=%{redirect_url}\n" "$U"
done
curl -s "$U" | grep -oE '<link rel="canonical"[^>]*>|<meta property="og:url"[^>]*>'
```

결과: 두 사용자 에이전트 모두 `HTTP 200`, 리디렉션 주소 없음. 페이지의 `canonical`과 `og:url`은 개인 도메인 주소를 가리켰다. 자기 블로그나 옮기려는 블로그에서 같은 명령으로 확인할 수 있다.

## 4. 워드프레스 개인 사이트 비용 계산

- 호스팅 월 3,000~5,000원 × 12 = 36,000~60,000원
- 도메인 연 약 20,000원
- 합계 연 약 56,000~80,000원
- 관리 시간: 평소 월 2~3시간 × 12 = 연 24~36시간, 장애가 난 달은 5시간쯤이라 그만큼 더 붙는다.

## 한계

- Search Console 집계는 한 블로그의 16개월 범위다. 하락 원인을 이 데이터만으로 확정하지 않는다.
- 순위대별 CTR은 3개월 간격 6개 월만 집계했다.
- 글별 분해는 글 번호로 나눈 근사 분류이고 1~3위 행만 셌다.
- 개인 도메인 연결 블로그 요청은 1곳, 1회 관찰이다. 티스토리가 정책을 바꾸면 결과가 달라질 수 있다.
- 비용은 공유 호스팅 한 곳의 범위값으로 계산했다.
