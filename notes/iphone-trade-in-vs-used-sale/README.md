## 4. 판매 완료 글로 직거래 범위를 내는 절차

예시 숫자 없이 절차와 식만 적는다.

1. 번개장터에서 같은 모델·같은 용량을 검색하고 판매 완료 필터를 켠다. 상태 표기(A급·B급 등)가 내 기기와 같은 글만 남긴다.
2. 표본 수 n을 센다. n < 10이면 범위를 확정하지 않는다.
3. 가격을 오름차순으로 정렬한다: p(1) ≤ p(2) ≤ … ≤ p(n).
4. 양 끝에서 k건씩 뺀다. k는 1 또는 2이며, n이 작을수록 1로 둔다.
5. 직거래 범위 = [p(k+1), p(n−k)]
6. 같은 날 받은 매입 견적 Q와 비교한다: 차액 D = p(k+1) − Q (보수적으로 범위의 아래쪽을 쓴다).
7. 판정: D > 기준액이면 직거래, D ≤ 기준액이면 Apple·매입업체 중 편한 쪽.
8. 기준액 = 직거래 1건 소요 시간(시간) × 내가 정한 시간 단가(원/시간). 글의 기준은 3시간 × 시간당 3만 원 초반 ≈ 10만 원.

호가만 보이는 용량(거래가 적은 512GB 등)은 3단계에 넣지 않는다.
